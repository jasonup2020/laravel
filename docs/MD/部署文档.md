## 本地开发部署

### 1. 克隆项目

```bash
git clone https://github.com/your-repo/laravel-saas-platform.git
cd laravel-saas-platform
```

### 2. 安装依赖

```bash
composer install
```

### 3. 配置环境

```bash
# 复制环境配置
cp .env.example .env

# 生成应用密钥
php artisan key:generate
```

### 4. 配置数据库

编辑 `.env` 文件：

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_saas
DB_USERNAME=laravel_saas
DB_PASSWORD=aesRs7T4S2
```

创建数据库：

```sql
CREATE DATABASE laravel_saas CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'laravel_saas'@'localhost' IDENTIFIED BY 'aesRs7T4S2';
GRANT ALL PRIVILEGES ON laravel_saas.* TO 'laravel_saas'@'localhost';
FLUSH PRIVILEGES;
```

### 5. 运行安装命令

```bash
php artisan saas:install
```

此命令会自动执行：
- 数据库迁移
- 数据填充
- 创建存储链接
- 清除缓存

### 6. 启动开发服务器

```bash
php artisan serve
```

访问：http://localhost:8000

## Docker部署

### 1. 克隆项目

```bash
git clone https://github.com/your-repo/laravel-saas-platform.git
cd laravel-saas-platform
```

### 2. 配置环境

```bash
cp .env.example .env
```

编辑 `.env` 文件，配置数据库连接：

```env
DB_HOST=mysql
DB_DATABASE=laravel_saas
DB_USERNAME=laravel_saas
DB_PASSWORD=aesRs7T4S2
```

### 3. 构建并启动容器

```bash
# 构建容器
docker-compose build

# 启动容器
docker-compose up -d

# 查看容器状态
docker-compose ps
```

### 4. 初始化应用

```bash
# 进入PHP容器
docker-compose exec php bash

# 安装依赖
composer install

# 生成密钥
php artisan key:generate

# 运行安装命令
php artisan saas:install

# 退出容器
exit
```

### 5. 访问应用

- **应用**: http://localhost
- **phpMyAdmin**: http://localhost:8080 (需要启用tools profile)
- **Redis Commander**: http://localhost:8081 (需要启用tools profile)

### Docker常用命令

```bash
# 启动所有服务
docker-compose up -d

# 停止所有服务
docker-compose down

# 重启服务
docker-compose restart

# 查看日志
docker-compose logs -f

# 进入PHP容器
docker-compose exec php bash

# 进入MySQL容器
docker-compose exec mysql bash

# 启动完整服务（包含Elasticsearch）
docker-compose --profile full up -d

# 启动工具服务（phpMyAdmin、Redis Commander）
docker-compose --profile tools up -d
```

## 生产环境部署

### 1. 服务器准备

#### 安装PHP 8.3

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install php8.3 php8.3-fpm php8.3-mysql php8.3-redis php8.3-mbstring php8.3-xml php8.3-curl php8.3-zip php8.3-gd php8.3-intl php8.3-bcmath

# CentOS/RHEL
sudo yum install epel-release
sudo yum install php83 php83-php-fpm php83-php-mysqlnd php83-php-redis php83-php-mbstring php83-php-xml php83-php-curl php83-php-zip php83-php-gd php83-php-intl php83-php-bcmath
```

#### 安装Nginx

```bash
# Ubuntu/Debian
sudo apt install nginx

# CentOS/RHEL
sudo yum install nginx
```

#### 安装MySQL 8.0

```bash
# Ubuntu/Debian
sudo apt install mysql-server

# CentOS/RHEL
sudo yum install mysql-server
```

#### 安装Redis

```bash
# Ubuntu/Debian
sudo apt install redis-server

# CentOS/RHEL
sudo yum install redis
```

### 2. 部署代码

```bash
# 创建目录
sudo mkdir -p /var/www/saas-platform
sudo chown -R $USER:$USER /var/www/saas-platform

# 克隆代码
cd /var/www/saas-platform
git clone https://github.com/your-repo/laravel-saas-platform.git .

# 安装依赖（生产环境）
composer install --no-dev --optimize-autoloader

# 配置环境
cp .env.example .env
php artisan key:generate
```

### 3. 配置环境变量

编辑 `.env` 文件：

```env
APP_NAME="SaaS Platform"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-domain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_saas
DB_USERNAME=laravel_saas
DB_PASSWORD=your_secure_password

REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379
```

### 4. 初始化数据库

```bash
php artisan migrate --force
php artisan db:seed --force
```

### 5. 优化应用

```bash
# 缓存配置
php artisan config:cache

# 缓存路由
php artisan route:cache

# 缓存视图
php artisan view:cache

# 创建存储链接
php artisan storage:link
```

### 6. 设置权限

```bash
sudo chown -R www-data:www-data /var/www/saas-platform
sudo chmod -R 755 /var/www/saas-platform
sudo chmod -R 775 /var/www/saas-platform/storage
sudo chmod -R 775 /var/www/saas-platform/bootstrap/cache
```

### 7. 配置Nginx

创建Nginx配置文件：

```bash
sudo nano /etc/nginx/sites-available/saas-platform
```

内容见 [Nginx配置](#nginx配置) 章节。

启用站点：

```bash
sudo ln -s /etc/nginx/sites-available/saas-platform /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 8. 配置Supervisor（队列进程）

```bash
sudo apt install supervisor
```

创建配置文件：

```bash
sudo nano /etc/supervisor/conf.d/saas-platform.conf
```

```ini
[program:saas-horizon]
command=php /var/www/saas-platform/artisan horizon
autostart=true
autorestart=true
user=www-data
redirect_stderr=true
stdout_logfile=/var/www/saas-platform/storage/logs/horizon.log
```

启动Supervisor：

```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start saas-horizon
```

### 9. 配置定时任务

```bash
sudo crontab -u www-data -e
```

添加：

```
* * * * * cd /var/www/saas-platform && php artisan schedule:run >> /dev/null 2>&1
```

## Nginx配置

### 基础配置

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/saas-platform/public;

    index index.php index.html index.htm;

    # 日志
    access_log /var/log/nginx/saas-access.log;
    error_log /var/log/nginx/saas-error.log;

    # 主配置
    charset utf-8;
    client_max_body_size 20M;

    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_types text/plain text/css text/xml application/json application/javascript application/rss+xml application/atom+xml image/svg+xml;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # 静态资源缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }

    # 主要路由
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP处理
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }

    # 禁止访问隐藏文件
    location ~ /\. {
        deny all;
    }

    # 禁止访问敏感文件
    location ~* \.(env|log|git|gitignore)$ {
        deny all;
    }
}
```

### HTTPS配置

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;
    root /var/www/saas-platform/public;

    # SSL证书
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # SSL配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;

    # 其他配置同上...
}

# HTTP重定向到HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

## 性能优化

### 1. OPcache配置

编辑 `php.ini`：

```ini
opcache.enable=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=10000
opcache.max_wasted_percentage=10
opcache.use_cwd=1
opcache.validate_timestamps=0  # 生产环境设为0
opcache.revalidate_freq=0
opcache.fast_shutdown=1
```

### 2. Redis缓存

配置Redis作为缓存和Session驱动：

```env
CACHE_DRIVER=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis
```

### 3. 数据库优化

```sql
-- 配置MySQL
SET GLOBAL innodb_buffer_pool_size = 1073741824;  -- 1GB
SET GLOBAL innodb_log_file_size = 268435456;      -- 256MB
SET GLOBAL max_connections = 200;
```

### 4. 队列优化

使用Horizon管理队列：

```bash
php artisan horizon
```

## 常见问题

### 1. 权限问题

```bash
sudo chmod -R 775 storage bootstrap/cache
sudo chown -R www-data:www-data storage bootstrap/cache
```

### 2. Composer内存不足

```bash
COMPOSER_MEMORY_LIMIT=-1 composer install
```

### 3. Nginx 502错误

检查PHP-FPM是否运行：

```bash
sudo systemctl status php8.3-fpm
sudo systemctl restart php8.3-fpm
```

### 4. 数据库连接失败

检查MySQL服务：

```bash
sudo systemctl status mysql
sudo systemctl restart mysql
```

### 5. Redis连接失败

检查Redis服务：

```bash
sudo systemctl status redis
sudo systemctl restart redis
```

### 6. 队列不执行

检查Supervisor：

```bash
sudo supervisorctl status
sudo supervisorctl restart saas-horizon
```

## 更新部署

```bash
cd /var/www/saas-platform

# 拉取最新代码
git pull origin main

# 安装依赖
composer install --no-dev --optimize-autoloader
```

## 回滚操作

```bash
cd /var/www/saas-platform

# 回滚到上一个版本
git reset --hard HEAD~1

# 重新安装依赖
composer install --no-dev --optimize-autoloader

# 回滚迁移
php artisan migrate:rollback --step=1

# 清除并重建缓存
php artisan config:clear && php artisan config:cache
php artisan route:clear && php artisan route:cache
php artisan view:clear && php artisan view:cache

# 重启服务
sudo systemctl reload php8.3-fpm
sudo systemctl reload nginx
```
