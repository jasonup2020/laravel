## 🚀 快速开始

### 1. 本地安装

```bash
# 克隆项目
git clone https://github.com/your-repo/laravel-saas-platform.git
cd laravel-saas-platform

# 安装依赖
composer install

# 配置环境
cp .env.example .env
php artisan key:generate

# 运行安装命令
php artisan saas:install

# 启动服务
php artisan serve
```

### 2. Docker部署

```bash
# 启动Docker容器
docker-compose up -d

# 进入容器初始化
docker-compose exec php bash
composer install
php artisan key:generate
php artisan saas:install
```

### 3. 默认账号

- **用户名**: admin
- **密码**: admin123

## 📝 代码规范

### 编码标准
- PSR-12编码规范
- 完整的PHPDoc注释
- 4空格缩进
- UTF-8编码
- 每行不超过120字符

### 命名规范
- 类名：大驼峰（UserController）
- 方法名：小驼峰（getUserInfo）
- 变量名：小驼峰（$userName）
- 常量：全大写下划线（MAX_ATTEMPTS）
- 数据库表名：复数小写下划线（users）
- 字段名：小写下划线（user_id）
- 路由：小写短横线（user-list）

### 架构规范
- 控制器：只处理请求响应
- 服务层：所有业务逻辑
- 模型：数据访问和关联
- 请求验证：FormRequest类
- 资源转换：Resource类
- 异常处理：自定义异常类
